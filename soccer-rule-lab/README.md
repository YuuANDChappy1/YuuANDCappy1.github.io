# オフサイド・ラボ

親子で選手を動かしながらオフサイドを学ぶ、HTML・CSS・JavaScriptだけのWebアプリです。外部API・バックエンド・ビルド作業・ライブラリは使いません。

動かし方と確認方法

1. 青い「9 / FW」を右にドラッグ。黄色い守備側の基準ラインを越えると、判定と理由、3つの条件がすぐに変わります。
2. 赤いDF・GKを動かします。相手ゴール（右）に近い順に数え、後ろから2人目の位置に黄色い線が移ります。
3. ボールをFWより前へ動かすと、守備側の線を越えていてもオンサイドになります。
4. 「同じラインなら？」で、FWとDFが同じ位置ならオンサイドになることを確認できます。
5. 「自陣にいるとき」で、自陣では相手より前でもオンサイドになることを確認できます。
6. 「初期配置に戻す」で最初の状態に戻ります。

スマートフォンでは指でドラッグします。ピッチ以外の場所は通常どおりスクロールできます。キーボードではTabで選手やボールを選択し、矢印キーで1単位、Shift + 矢印キーで5単位ずつ移動できます。座標は0〜100の整数にそろえるため、同じラインに合わせやすくなっています。画面幅が変わっても配置は保持されます。
